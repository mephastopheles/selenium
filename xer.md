### Характеристика возможностей AnyLogic PLE:
AnyLogic PLE (Personal Learning Edition) - бесплатная версия для обучения, поддерживающая:
- Создание дискретных, агентных и системно-динамических моделей
- Основные функции профессиональной версии с ограничением на размер модели
- Экспорт в формат HTML5 для веб-демонстраций
- Отсутствие коммерческого использования

### Поддерживаемые концепции имитационного моделирования:
1. Дискретное событийное моделирование
2. Агентное моделирование
3. Системная динамика
4. Гибридные подходы

### Элементы для задания поведения агентов:
- Стейтчарты (Statecharts)
- Java-код (написание пользовательских функций)
- Параметры и переменные агентов
- Сообщения и события
- Коллекции и условия

### Доступные библиотеки в PLE:
1. Process Modeling Library (Библиотека процессов)
2. Pedestrian Library (Пешеходная библиотека)
3. Rail Library (Железнодорожная библиотека)
4. Fluid Library (Библиотека жидкостей)
5. Road Traffic Library (Дорожное движение)

### Области окна разработки:
1. Палитра элементов (слева)
2. Рабочая область модели (центр)
3. Свойства объектов (справа)
4. Проектное дерево (слева)
5. Панель анимации
6. Консоль ошибок

### Назначение общей библиотеки (Process Modeling):
Моделирование бизнес-процессов, логистических систем и производственных линий с использованием:
- Блоков обработки (Service, Delay)
- Очередей (Queue)
- Разветвлений (SelectOutput)
- Ресурсов (ResourcePool)

### Железнодорожная библиотека:
Для моделирования:
- Движения поездов
- Ж/Д инфраструктуры (стрелки, светофоры)
- Логистики на ж/д транспорте
- Расписаний движения

### Отличие пешехода от активного объекта:
Пешеход - специализированный агент с:
1. Физическими характеристиками (скорость, размер)
2. Навигацией в пространстве
3. Механизмами избегания столкновений
4. Интеграцией с пешеходной библиотекой

### Компоненты для статистики:
1. Dataset - сбор данных
2. Histogram - гистограммы
3. Plot - графики
4. Statistic - основные метрики
5. TimePlot - временные ряды

### Блок Source:
**Назначение:** Создание агентов  
**Параметры:**
- Arrival rate (интенсивность)
- Arrivals defined by (распределение)
- Agent type (тип создаваемых агентов)

### Блок для вывода агентов:
Sink (приемник) - удаляет агенты из модели

### Блок задержки:
1. Delay - фиксированное время
2. Service - с использованием ресурсов

### Понятие ресурса:
Сущность, необходимая для выполнения операций (например, рабочие, станки)

### Блоки для работы с ресурсами:
1. ResourcePool - пул ресурсов
2. Seize - захват ресурса
3. Release - освобождение
4. Service - захват+использование+освобождение

### Типы ресурсов:
1. Унитарные (единичные)
2. Множественные (пулы)
3. Транспортные
4. Специализированные

### Блок Service:
**Назначение:** Обслуживание с ресурсом  
**Параметры:**
- Delay time (время обработки)
- Resource pool (используемый ресурс)
- Capacity (количество единиц)

### Ограничение очереди:
Через параметр "Maximum capacity" в блоке Queue

### Задание модельного времени:
В свойствах модели:  
Model > Time > Time units (мин/сек/час)

### Блоки для копирования/объединения:
1. Clone - копирование
2. Combine - объединение
3. Batch - группировка

### Блок синхронизации:
Match - синхронизирует несколько потоков агентов

### Определение агента:
Автономная сущность с:
- Состояниями
- Поведением
- Памятью (переменными)
- Способностью принимать решения

### Свойства агентов:
- Параметры (характеристики)
- Переменные (состояние)
- Функции (поведение)
- Графическое представление

### Инструменты задания поведения:
1. Стейтчарты
2. События (Events)
3. Java-код
4. Библиотечные блоки

### Стейтчарты:
Визуальные диаграммы состояний с:
- Состояниями (прямоугольники)
- Переходами (стрелки)
- Условиями перехода
- Действиями при переходах

### Организация переходов:
Через триггеры:
- По времени (timeout)
- По сообщениям (message)
- По условиям (condition)
- По событиям (event)

### Эксперимент:
Набор прогонов модели с различными параметрами для анализа поведения системы

### Единичный опыт:
Один прогон модели с фиксированным набором параметров

### Планирование эксперимента:
Научный метод определения:
- Количество опытов
- Сочетания параметров
- Последовательности тестов

### Виды экспериментов:
1. Детерминированные
2. Стохастические
3. Факторные
4. Оптимизационные

### Этапы планирования:
1. Определение цели
2. Выбор факторов
3. Определение уровней
4. Составление плана
5. Проведение
6. Анализ

### Функция отклика:
Зависимость выходных параметров модели от входных факторов

### Порядок функции отклика:
Определяется числом учитываемых взаимодействий факторов (линейная, квадратичная)

### Поверхность отклика:
Графическое представление функции отклика в многомерном пространстве

### Факторный эксперимент:
Исследование влияния всех комбинаций факторов. Для N факторов с 2 уровнями нужно 2^N опытов.

### Метод кругового восхождения:
Поиск оптимальных параметров через последовательное приближение вдоль градиента

### Отсеивающий эксперимент:
Выявление наиболее значимых факторов из множества возможных

### Реализация в GPSS World:
Через:
- Множественные прогоны
- Изменение параметров через VARIABLE
- Сбор статистики через TABLE/QTABLE
- Анализ результатов
